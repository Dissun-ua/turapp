# turapp
 Prosjektoppgaven i APP2000 for studieåret 2025/2026 (turapp).

 Prompt for KI:

Lag en landingsside for "UT.ut" – et nettsted for turinteresserte,
utviklet for den fiktive Turistforeningen i Utopia (TiU). Utopia har
identisk geografi med Norge. Nettstedet skal gi informasjon om turruter,
turmål og hytter, og fungere som en sosial plattform der man kan melde
seg på og planlegge fellesturer.

Krav til koden:
- Kun HTML og CSS. Ingen JavaScript, ingen backend, ingen database.
- To filer: index.html og style.css
- Responsiv, skal fungere på mobil, nettbrett og PC
- Semantiske HTML-elementer (header, nav, main, section, footer)
- Norsk språk i all tekst
- Ingen eksterne bilder, bruk CSS-farger eller placeholder-bokser

Innhold på siden:
- Et tydelig banner helt øverst: "Studentoppgave ved USN"
- Header med logo og navigasjon: Turer, Hytter, Fellesturer, Kart,
  Logg inn
- Hero-seksjon med et søkefelt (kun visuelt) og en kort introduksjon
- Seksjon med filtre som viser hva man kan søke på: vanskelighetsgrad,
  varighet, turtype (fottur/sykkeltur/skitur)
- Seksjon med 3-4 kort for populære turruter, hver med navn, lengde,
  vanskelighetsgrad og stjernevurdering
- Seksjon med 3 kort for hytter, som viser om de er betjente eller
  ubetjente, prisnivå og fasiliteter
- Seksjon for kommende fellesturer, der det visuelt skilles mellom
  turer med fast startdato og turer med fleksibel startdato
- Footer med lenker og info om TiU
